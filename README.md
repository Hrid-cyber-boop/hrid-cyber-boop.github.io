## 🚀 How to Deploy on GitHub Pages

1. **Option A: User Site (Recommended for `https://hrid-cyber-boop.github.io`)**
   - Create a public repository named exactly: `hrid-cyber-boop.github.io`
   - Push all files from `code.zip` (`index.html`, `style.css`, `script.js`, `README.md`, and the `assets/` folder) to the `main` branch root.
   - GitHub Pages will automatically build and publish the website at `https://hrid-cyber-boop.github.io/`.

2. **Option B: Project Site (e.g. `https://hrid-cyber-boop.github.io/portfolio/`)**
   - Create a repository named `portfolio` (or any desired name).
   - Push the files to the `main` branch.
   - Go to **Settings** > **Pages** > Under **Build and deployment**, select **Deploy from a branch** > branch: `main` / `root` > Click **Save**.
   - Your site will be live at `https://hrid-cyber-boop.github.io/portfolio/`.
